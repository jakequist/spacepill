Visual tour

SpacePill, one screen at a time

Six surfaces, in the order you'll meet them: the pill, labelling a Space, jumping to one, the notes panel, Preferences, and the System Settings screen the Setup window points you to.

1 The pill

Where you are, without opening anything.

2 Quick Edit

⌘ ⇧ S — name and colour the Space you're on.

3 Quick Switch

⌘ ⇧ J — jump to a Space by typing part of its name.

4 Space Notes

⌘ ⇧ N — a Markdown scratchpad that belongs to this Space.

5 Preferences

Right-click the pill → Preferences…

6 The keyboard shortcuts that power switching

macOS has no API for changing Spaces, so SpacePill replays your own Switch to Desktop N shortcuts. They live in Keyboard Shortcuts, and SpacePill's Setup window helps you turn them on if any are off. How switching works →
