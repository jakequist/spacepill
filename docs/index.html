Native macOS menu bar app · macOS 13+

Always know which Space you're on.

SpacePill puts a big, colour-coded pill in your menu bar for the Space you're currently on — then gives you hotkeys to relabel it, jump straight to another one by name, and keep notes that follow each Space around.

Why it exists

Built for running a lot of agents at once

1 Agent A

One agent, one Space

SpacePill was written to make a specific workflow bearable: several coding agents running in parallel, each with its own Space, each doing something different.

2 Colour

Colour beats counting

The built-in Spaces indicator is a row of identical grey thumbnails behind a Mission Control gesture. A big coloured pill with a number tells you where you are without thinking about it.

3 Jump

Jump by name, not by position

Type part of a Space's label — or its number — and hit ⏎. You do not have to remember that “the refactor one” is the fourth desktop from the left.

4 Notes

Context that stays put

Each Space gets its own Markdown scratchpad. Switch away and it disappears; switch back and it is exactly where you left it, scroll position included.

See it in action

Type a few letters, land on the right Space

Fuzzy-match a Space by name and jump straight to it — the pill changes colour and label to match.

Features

Four things, done properly

Everything is keyboard-first, everything stays on your machine.

The pill

A capsule in the menu bar showing the current Space's number badge and its label in caps. Unconfigured Spaces show a neutral pill; if SpacePill can't read the current Space yet it shows ? rather than lying to you.

Quick Edit

Rename and recolour the Space you're on from a popover: a text field, seven presets (blue, red, green, orange, purple, pink, grey) and a full colour picker. New Spaces are pre-assigned the first unused preset.

⌘ ⇧ S

Quick Switch

A search bar over every Space on every display. Filter by label or by exact number, move with ↑↓, jump with ⏎. Spaces it genuinely cannot reach are greyed out with the reason, instead of silently doing nothing.

⌘ ⇧ J

Space Notes

A floating Markdown scratchpad pinned under the pill, with syntax highlighting for headings, bold, italics, code and lists, plus auto-continued list bullets. It saves as you type, and its border can take on the Space's colour.

⌘ ⇧ N

Default hotkeys — all three are rebindable in Preferences.

Install

Two ways in

Install script (recommended)

Terminal
curl -fsSL https://jakequist.github.io/spacepill/install.sh | sh

Downloads the latest signed release, installs SpacePill.app into /Applications, launches it, and adds the optional spacepill CLI. macOS only.

Direct download

Grab the signed and notarised SpacePill.dmg from the latest release and drag it to Applications.

Latest release →

Or build it yourself

Terminal
git clone https://github.com/jakequist/spacepill.git
cd spacepill
./bin/start.sh

Requires Xcode command line tools. start.sh builds, assembles a signed .app bundle and launches it — running the bare SwiftPM binary will not work correctly.

Getting started

Five minutes, once

On first launch a Setup window walks you through everything below.

  1. Launch SpacePill

    It has no Dock icon and no window — look for the pill in the menu bar. If it shows ?, switch Spaces once to wake up detection.

  2. Let the Setup window guide you

    On first launch SpacePill opens a Setup window that checks everything for you: the two permissions, whether the “Switch to Desktop” shortcuts are on, and whether Quick Switch and Space Notes are enabled — with a button through to each System Settings pane. Reopen it any time from the pill's right-click menu.

  3. Grant the permissions it asks for

    Accessibility lets SpacePill post the keystrokes that change Spaces. Input Monitoring only makes the pill update the instant a switch begins. Both live under System Settings → Privacy & Security. What breaks without each →

  4. Enable Quick Switch and Space Notes

    Right-click the pill → Preferences… Both features ship switched off; their hotkeys are not registered until you turn them on.

  5. Name your Spaces

    Go to a Space, press ⌘ ⇧ S, type a label, pick a colour, ⏎. Repeat. Labels and colours are stored against the Space's UUID, so they survive reordering.

Privacy

Nothing leaves your Mac

SpacePill has no telemetry, no accounts and no network code. Labels, colours, settings and notes are plain files in ~/.spacepill/. It is a single SwiftPM executable with no third-party dependencies, released under the MIT licence.
